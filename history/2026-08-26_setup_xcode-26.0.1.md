# 2026-08-26 setup xcode-26.0.1

## 한 일

로컬에 Xcode 26.0.1을 설치하고, 설계/README 툴체인 절을 그 버전에 맞게 고쳤다. 앱 코드는 없다.

## 왜

2026-08-24 문서는 CLT 16.4 + Swift 6.1.2만 있었고 `xcodebuild`가 불가했다. SwiftUI/AppKit `.app` 스파이크를 하려면 Xcode가 필요하다. 사용자가 26.0.1을 지정했다.

## 확인한 것

- `/Applications/Xcode-26.0.1.app`
- `xcode-select -p` → `/Applications/Xcode-26.0.1.app/Contents/Developer`
- `xcodebuild -version` → Xcode 26.0.1 / Build 17A400
- `swift --version` → Apple Swift 6.2 (swiftlang-6.2.0.19.9)

## 바꾼 것

- `docs/design.md` 툴체인 절 (2026-08-26)
- `README.md` 빌드 상태

## 넣지 않은 것

SwiftUI 앱, Xcode 프로젝트, 커밋.
