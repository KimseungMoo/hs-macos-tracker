# 덱·픽 추천: Arena 점수만

추천은 HearthArena **숫자 점수**만 쓴다. 커브 구멍, 직업 시너지, 패키지, 매치업, HSReplay 승률, 가능한 30장 조합을 모두 계산하지 않는다. 너무 복잡하고 입력도 없다.

점수는 앱이 웹에서 긁지 않는다. 사용자가 가져온 로컬 점수 파일만 쓴다. 숫자 없으면 추천하지 않는다.

구현은 `ArenaScore` (`Core/GameState/ArenaScore.swift`). Release 바이너리의 투기장 추천은 기존처럼 flag 기본 OFF.

## 비교 키

유효 점수 = **직업 점수 ?? 공통 점수**.

- 같은 카드가 직업/뉴트럴로 갈리면 지금 히어로 직업 점수.
- 레터 등급(S/A/B/C/D/F)은 표시용 버킷이다. 정렬·동점·2등 판정에 쓰지 않는다.
- 숫자와 레터가 모순이면 숫자. 예: 점수 72 + 레터 S → 72.

레터만 있고 숫자가 없으면 점수가 없는 것과 같다. 그 카드는 고르지 않는다.

표시용 버킷(숫자가 있을 때만):

| 점수 | 레터 |
| --- | --- |
| ≥100 | S |
| 90–99 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| ≤59 | F |

## 카드 등급이 다를 때

레터가 달라도, 같아도, 숫자만 본다.

- 같은 A: 98 > 91. A끼리라고 동점이 아니다.
- 레터가 다름: B 89 < A 90. 1점 차이도 숫자가 이긴다.
- 한 장은 S인데 숫자가 낮고, 다른 장은 C인데 숫자가 높으면 높은 숫자.

동점은 **유효 점수가 완전히 같을 때**만. 커브·시너지로 깨지 않는다. 표시는 동점. 내부 순서는 cardID 오름차순으로만 고정한다.

## 3장 픽

세 장 모두 유효 점수가 있을 때만 고른다. 한 장이라도 없으면 추천하지 않는다.

순서: 점수 내림차순 → 픽 / 차선 / 패스. 1픽 전설 버킷도 같은 식이다. 버킷 평균을 따로 계산하지 않는다.

## 30장 덱

보유 카드 중 점수 있는 것만, 점수 높은 순으로 장수 상한까지 채운다. 전설은 호출측이 `maxCopies = 1`을 넣는다.

- 점수 없는 카드는 빼고 채운다. 추정하지 않는다.
- 30장이 안 되면 있는 만큼만 주고 `incomplete`.
- 덱 안에 S와 F가 섞여도 평균·최저로 다시 줄 세우지 않는다. 이미 점수 순이다.
- 아키타입 이름, 인기 30코드, 상대 직업 승률은 쓰지 않는다.

## 하지 않는 것

- 2–4드롭 구멍, 직업 패키지 1장으로 축 열기, 후반 가치 보정
- HSReplay 인기 리스트·전적·H2H로 30장 조립
- 로컬 휴리스틱(코스트, 공격력, rarity, mechanics 테이블)으로 점수 대체
- 없는 점수 발명
