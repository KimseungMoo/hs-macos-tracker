# 추가 기능 아이디어

아직 구현하지 않는다. 정책([policy.md](policy.md))과 충돌하면 아이디어만 남기고 막는다.
런타임 HSReplay/HearthArena 스크래핑, 상대 손·덱·비밀은 금지.

## 1. 다국어

- UI 문자열 분리. 1차는 ko / en, 다음 ja.
- 카드명은 카탈로그 `name` 맵. 입력은 어느 로케일이든 CardID로 붙임.
- `Power.log`는 CardID라 언어와 무관.
- OCR은 로케일별 fixture. 실패 시 수동.

## 2. 최신 직업 티어

- 직업 승률/픽률 표. 포맷(Underground 등)과 날짜 창을 명시.
- 데이터는 build-pinned 스냅샷 또는 사용자 가져오기 파일.
- 앱이 웹을 긁지 않음. 사람이 갱신하거나 권리 확인된 adapter만.

## 3. 최신 직업별 카드·덱 티어

- 직업별 카드 점수, 공개 아키타입 덱 티어.
- 2와 같은 공급 규칙. 제3자 점수표 전체는 저장소에 안 넣음.
- 런타임 로컬 휴리스틱과 티어 표는 경로를 분리. 티어는 참고, 강제가 아님.

## 4. 인플레이: 경우의 수 등급 + 실시간 승률

- 지금 Advice는 lethal / 마나 / 위협 / 제거 리마인더만. 등급 없음.
- 공개 상태만으로 분기(페이스 / 트레이드 / 패스 등)마다 등급(예: A–D).
- “승률”은 숨은 정보 없는 로컬 추정치. 서버 실시간 WR 아님.
- 처방형(이 카드·저 대상)은 기존 flag. 승인 전 Release OFF.

## 5. 상대 덱 예상

- 공개된 상대 카드 + 직업 + 티어 스냅샷으로 아키타입 후보만.
- 상대 손·남은 덱·비밀은 읽지 않음. 로그에 CardID가 있어도 Visibility에서 버림.
- 확신 낮으면 `unknown`. 추정으로 조언하지 않음.

## 후순위 메모

- 공급 계약·Blizzard 승인 전엔 2·3·4(처방)·5의 공개 배포를 열지 않음.
- App/ 오버레이(Xcode 26.0.1)와 실로그 검증이 먼저다.
